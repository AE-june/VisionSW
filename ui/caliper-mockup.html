구조

  • ① Profile — 고정. ✎ Draw ROI armed 상태에서 차트 위 드래그 → 새 Element. 밴드 가장자리 핸들 드래그 → 범위 조절.
  • ② Elements — 스크롤. 클릭 → 인라인 확장(Properties). type=point/line 전환. point는 kind별 파라미터 다름.
  • ③ Measurements — 스크롤. 2단계 선택: ① 대상 조합(combo) → ② 조합 내 세부 metric. combo가 slot 결정, slot엔 호환 타입 Element만.
  • ④ Results — 종합 배너 + Measurement 카드(주) + Element raw값(접힘, 보조).

Results 구성

  • 종합 배너 — allPass 크게 PASS/FAIL + "1/2 out of tol" 요약
  • Measurement 카드 — 측정값(큰 글씨) + tolerance 바(초록=허용범위, 회색선=nominal, 점=실측) + 편차(dev). 검사 핵심이라 주 표시
  • Element raw — 접힘 기본. 펼치면 R0 s/z, R1 slope/intercept/rmse 등 디버깅용 원시값

Measurement 2단계

① combo 고르면 slot 생김 + metric 후보 좁혀짐 → ② metric 선택:

  • point·point → [pt][pt] · metric: euclidean deltaS deltaZ
  • point·line → [pt][ln] · metric: perpDist
  • line·line → [ln][ln] · metric: angle offset
  • line → [ln] · metric: tilt flatness
  • point → [pt] · metric: absS absZ
