결과 탭 vs 파라미터 탭

파라미터 탭: ROI/measure 설정·편집 (편집용)
결과 탭: 실행 결과 표시 (읽기전용)

결과 탭 구성

  • 종합 배너 — allPass PASS/FAIL 최상단
  • Profile 차트 — ROI 밴드(옅게) + 마커 + 라인피팅 + 측정 주석(거리선/라벨을 차트 위에 직접). 어느 측정이 어디인지 시각 확인
  • Measurement 표 — name/value/target/dev/판정. 검사 핵심 수치 표 형태로 깔끔하게
  • Element raw — 접힘. slope/intercept 등 원시값

차트 측정 주석

  • point·point → 두 점 잇는 점선 + 라벨
  • point·line → 점에서 선까지 수선 + 라벨
  • line·line angle → 교차부 호(arc) + 각도
